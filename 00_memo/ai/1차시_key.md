# Feature / Label
- 데이터가 왜 중요할까
    - 머신 러닝은 규칙을 직접 코딩하지 않고, 데이터에서 규칙을 학습한다.
    - 데이터 (Feature, Label)의 분포와 관계가 머신러닝의 학습 결과를 결정한다.

- Feature (피처, 특성)
    - 모델이 예측에 사용하는 입력 정보
    - 예측, 판단의 근거 / 단서

- Label (라벨, 목표값)
    - 모델이 예측하려는 정답
    - 학습의 목표값

- 예시
    - 유튜브 추천 영상
        - Feature: 각 영상들의 정보(장르, 크리에이터, 조회수, 좋아요 수 등), 사용자 정보(시청 이력, 구독 채널 등)
        - Label: 영상에 대한 사용자 피드백 (시청 여부, 좋아요 클릭 여부)

    - 스팸메일 분류
        - Feature: 메일 제목, 발신자, 단어 빈도
        - Label = 스팸 / 정상

    - 피처는 원데이터, 즉 source. 라벨은 그에 대한 판단.

    - 1D 피쳐 기반 학습 : feature 가 한 개일 때 머신러닝

**학습이란**
- 입력(feature) 과 출력(label)의 관계를 찾는 과정
- 가설 공간: 관계를 표현할 수 있는 수없이 많은 함수들의 모음


# 회귀, Regression
- 예측하고 싶은 결과값이 `숫자`일 때 사용
- like 가격, 점수, 온도
- 정의: feature로부터 숫자(label)을 얼마나 정확히 예측할까?
- 특징: 라벨 및 예측 모델의 출력은 연속적인 수치
- 결국 라벨이 숫자인 지도학습
  
- 평균 제곱 오차, MSE, Mean Squared Error
    - 각 데이터에서 정답과 예측의 평균 제곱 차
    - 틀린 정도를 제곱해서 오류에 더 큰 패널티 부여
    - RMSE = MSE ^ -1/2
    ![MSE](/00_memo/ai/properties/MSE.png)

- **회귀 설명력: 결정계수, R\*\*2**
    - label의 분산 중에서 Feature 로 설명되는 비율
    - 평균만 쓰는 단순한 예측 보다 모델이 실제값을 얼마나 잘 맞추는지 0~1 사이 값으로 나타냄
    - 1에 가까울수록 설명력이 높고 낮을수록 설명력이 낮음
        - 모델링을 잘하면 1에 가깝고 아니면 작아진다.
    - MSE 에서 1/n 을 안한 값 -> MSE 값과 비례한다.
    - y 값이 얼마나 퍼져있는지를 나타낸다.
    - R**2 은 음수가 나올 수 있나?
        - 나올 수 있다. -> 모델링이 형편 없다는 뜻 ( 예측값이 평균값보다 못하다. )
    ![R**2](/00_memo/ai/properties/R2.png)


# 혼동행렬, COnfusion Matrix
![혼동](/00_memo/ai/properties/confusion.png)
- 예측과 실제 값 사이의 관계를 행렬 형태로 표현
    - 약간 진리표 같이 생겼음
- TP: 실제 양성, 예측 양성 > 성공 ( True Positive )
- TN: 실제 음성, 예측 음성 > 성공 ( True Negative )
- FP: 실제 음성, 예측 양성 > 실패, **오탐** ( False Positive )
- FN: 실제 양성, 예측 음성 > 실패, **누락** ( False Negative)
  
- 정밀도: Positive 중 True Positive 의 비율 ( 양성 판정 중 진짜 양성 비율 )
- 재현율: Actual Positive 중 True Positive 의 비율 ( 진짜 양성 중 양성 판정 비율 )
- F1-score: 정밀도와 재현율의 조화평균, 클 수록 좋다
    - F1 = 2 * ( 정밀도 * 재현율 / ( 정밀도 + 재현율 ) )
