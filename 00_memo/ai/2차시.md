# 로지스틱 회귀
- 로지스틱 회귀의 모형식, MLE (Maximum Likelihood Estimation)
- 시그모이드 함수, Sigmoid 를 활용해 0~1 범위 내 확률값 예측 보장
- 순서가 없는 범주를 확률로 직접 예측하는 적절한 분류 방법
- 로지스틱 함수는 선형 함수를 내포하고 있다.
- 로지스틱 모형은 선형 모형식과 시그모이드 함수의 결합이며 로짓 변환시 선형 회귀 모형식으로 표현이 가능하다.
- 우도: 확률함수가 데이터를 얼마나 잘 설명하는지를 나타낸 지표

# 경사하강법, Gradient Descent
- 손실함수의 값이 줄어드는 방향으로 파라미터를 이동하는 과정
- 기울기에 따라서 내려가겠다.
- 손실함수를 최소화하기 위해 파라미터를 반복적으로 갱신하는 알고리즘
- 기울기 계산: 손실함수를 파라미터에 대해 편미분 진행
