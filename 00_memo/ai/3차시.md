# RNN
- 전통적인 인공 신경망: 고정된 길이의 입력을 받아 가변 길이의 데이터를 처리하기에 적합하지 않다.
- RNN 은 가변 길이의 입력을 받을 수 있고 이전 입력을 기억할 수 있어서 순차적 데이터 처리에 적합한 아키텍처이다.
- 이전 정보를 담는 hidden state 를 가지고 있다.

- 한 번에 하나의 요소를 처리하고 정보를 앞으로 전달한다.
- 펼쳐서 보면 RNN은 각 층이 하나의 시점을 나타내는 신경망 처럼 보인다.
- RNN 은 hidden state 를 유지하면서 가변 길이 데이터를 처리할 수 있다.
- RNN의 출력은 과거 입력에 영향을 받는다는 점에서 feedforward 신경망과 다르다.
