# 선호학습, Preference Learning
- 선호학습: 다양한 응답 중 사람이 더 선호하는 응답을 생성하도록 추가학습
- Chat GPT 를 만들기 위한 핵심 알고리즘
1. 지시 학습을 통한 텍스트 파운데이션 모델의 추가학습
2. 사람의 선호데이터를 수집해 보상모델(Reward model, RM) 학습
3. 보상이 높은 응답을 생성하도록 강화학습을 통해 추가학습
> 지시학습 -> 보상모델 학습 -> 강화학습
  
# 디코딩 알고리즘, Decoding
- 거대언어모델의 자동회귀 생성 ( Auto-regressive Generation )
- LLMs 가 뱉어낸 확률 중 출력할 값을 선택하는 알고리즘
- 핵심: Greedy Decoding: 확률이 가장 높은 토큰을 선택
    - 사용하기 쉽지만 전역적 최적해를 보장하지 못함
- Beam Search: 확률이 높은 k 개의 후보를 동시 고려, DP 느낌
    - 최적해 보장 확률이 높지만 연산이 많아진다.
- Sampling: 확률을 기준으로 랜덤하게 생성
    - 다양한 응답이 나오지만 품질이 낮아질 수 있음
- Sampling with Temperature: 하이퍼 파라미터를 통해 확률 분포를 임의로 조작.
- TOP k Sampling: 확률이 높은 k 개의 토큰들 중 랜덤 확률
- TOP P sampling or Nucleus Sampling: K 를 고정하는 대신 누적확률에 집중해 K를 조절

실제로는 Temperature 와 Nucleus 를 사용한다.

- Temperature 를 0으로 두면 출력값을 고정할 수 있음. (완벽x)

# 거대 언어 모델의 평가
- 구축한 시스템이 실제로 잘 동작하는지 확인하는 단계
    - 테스트 데이터 기반:
    - 목표: 테스트 데이터 통과
    - 평가 방법: 테스트 데이터에 대한 예측과 정답을 비교
    - 평가 지표: 테스트 데이터 셋에서의 평균 정확도

- 거대 언어 모델은 특정 테스크에서 학습된 기존 AI 모델들과 달리 다양한 테스크에 대해 동시에 학습된다.

- 평가 방법의 종류
    - 정답이 정해진 경우
        - 예측과 정답을 비교하여 일치도를 측정: 정확도
    - 정해지지 않은 경우
        - ex 문서 요약, 스토리 생성
        - 사람이 Standard 를 정하고 얼마나 비슷한지 판단
        - 선호학습: 생성 텍스트의 유저의 상대적 선호를 평가할 수 있음
