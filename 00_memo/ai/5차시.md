# CNN?

## 합성곱 레이어
- 차원에 주의해야한다. Filter 는 항상 입력의 깊이 / 채널 축과 동일한 차원이어야 한다.

## F, C
- F 는 말하자면 1차원 배열이고 C 는 2차원 배열이라 더 디테일한 정보를 담을 수 있다.
- FCN 은 1차원 구조로 변환하는데 CNN은 3차원 구조를 그대로 보존하면서 연산한다.

## CNN
- 점진적으로 작은 스케일부터 큰 스케일로 이동하게 된다. 예: 엣지 > 색상 > 객체 > 이미지 특징

- 이미지의 작은 부분인 "지역 정보"를 추출하는데 유리하게 설계 > 작은 필터로 지엽적으로 주변 픽셀의 연관관계 판단하니까
- 이미지 활용하는 다양한 작업에서 이미지 전체(맥락)의 의미 파악 필요
  - 따라서 지역정보 + 이미지 전체의 맥락을 이해 / 활용하기 위한 설계가 필요하다.

- 수용영역? :
  - CNN이 이미지를 처리하며 한 번에 볼 수 있는 영역의 크기
  - 네트워크의 시야
  - 일반적으로 네트워크가 깊어질 수록 수용역역도 넓어진다. > 폭 넓은 맥락을 이해할 수 있다.
> 한 픽셀 출력을 위해서는 그 픽셀을 중심으로 하는 3*3 필드의 정보가 필요하다 (반복) > 개 미친 재귀
  - 가장자리가 중요하다. / 컨볼루션 레이어가 많이 필요하다.

- 풀링? :
  - 효율적 연산 및 위치 변화의 강건성 확보
  - 위치 변화 강건성:
    - 입력 내 위치가 다소 변해도 동일한 출력을 제공
    - 몇 화소 이동은 무시된다.
  - CNN 레이어의 출력을 줄여 연산 효율성을 확보: 입력 크기가 줄면 CNN 의 연산량이 크게 줄어듦
  - 맥스 풀링 :
    - 정해진 커널 사이즈로 이미지를 나누어 각 영역 내 가장 큰 값을 선택하는 연산.
    - 분할정복

- 스트라이드 합성 곱
  - 맥스 풀링과 같은 원리
  - 필터를 스트라이드 값 만큼 이동한 후 출력 연산
  - 풀링 처럼 입력 해상도를 줄인다. ( 연산 효율과 위치 강건성 )
  - 풀링 vs 스트라이드 :
    - 풀링은 학습 상수가 없지만 스트라이드는 커널을 동시에 학습
    - 고도화된 CNN 에서는 스트라이드 합성곱이 풀링 대신 활용되는 경향이 있다.

  - 풀링과 같은 역할을 수행하는데 최근에 더 선호되는 방법

## RNN, Recurrent Neural Nets
- 순차적 정보를 처리하기 위해 고안된 신경망 구조
- 순차적 정보 반영: 이전 단계 데이터를 은닉 상태로 다음 단계에 전달
  - 시간 / 순서의 흐름을 반영할 수 있다.
- 시계열/언어 데이터 적합
- input > hidden 변환 > 이전 hidden 과 교체 > hidden 고려 및 출력
  
- RNN 셀
