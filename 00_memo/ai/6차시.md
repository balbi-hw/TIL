# Foundation Model
- 기존 딥러닝 개발 패러다임: From scratch. 처음부터 모든 것들을 배워야한다.
- 파운데이션 모델 패러다임: 거대 모델 + 대규모 데이터 학습 기반
- 프로세스:
  - 데이터 생성 > 데이터 학습 > 훈련 > 적용

- 특징:
  1. [대규모]
    - 트랜스포머 모델 + 대규모 언어 데이터 학습
  2. [적응성]
    - 높은 파인튜닝 성능 (높은 태스크 적응 성능)
  3. [범용성]
    - 다양한 작업, 한정되지 않는 출력 지원

- 대표적 AI 파운데이션 모델 [ CLIP ]


# SigLIP
- 고도화된 CLIP
- softmax 대신 sigmoid 기반 손실함수를 사뇬한다.
- CLIP 을 사용한 대조학습의 한계를 뛰어 넘도록 손실함수 디자인을 고친 모델이다.
  - 일치하지 않는 음성 테이터에 제한된 영향만 받도록 > 값이 너무 커지지 않도록
- 최신 VLM 에 널리 사용된다.
- 대조학습 기반 언어-이미지 사전학습
  - 인터넷 데이터를 통한 지도 학습을 통해 자연어 기반 시각 개념 학습
  - 다양한 이미지 - 자연어 쌍으로 학습
