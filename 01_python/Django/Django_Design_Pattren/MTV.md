# MTV, Model-Template-View

여타 다른 언어들은 MVC 디자인 패턴을 사용하는데 장고는 MTV 를 사용한다. 뭐가 다른걸까?
  
![Nothing](../properties/Nothing.png)
  
다른게 없다. 그냥 이름만 다르다.
  
Model - View - Controller | Model - Template - View  
Template 은 View 에 대응하고 View 는 Controller 에 대응한다. 마치 미국 같다. 타의 추종을 불허하는 본인들만 사용하는 단위체계.. 제대로 홍대병이다.
  
어쩌겠는가! 이게 **PYTHONIC** 하시다는데!
  
아무튼 다른게 없다고 한 만큼 기능은 모두 같다. Template 은 프론트를 담당하고 View 는 컨트롤러이다. 뭐 설명할게 없을 정도이다.
  
찾다보면 차이점이 있다고는 하는데 Spring 의 그것과 크게 다른 점을 모르겠다. 추후 깨닫는 순간이 오면 수정하겠다!
