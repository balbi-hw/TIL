# ***MODEL***

데이터베이스와 Python 객체로 추상화된 형태로 상호작용 한다.

## Model class

DB의 테이블을 정의하고 데이터를 조작할 수 있는 기능들을 제공한다.
  
쉽게 데이터베이스 테이블의 구조를 설계하는 청사진 역할을 한다. 어떤 데이터(칼럼)을 저장할지, 그 데이터의 형태는 어떠할지를 Python 코드로 정의한다.
```python
# models.py
def Articls(models.Model):
    title = models.CharField(max_length=10)
    content = models.TextField()
```
이 코드는 DB에 테이블 구조를 만드는 코드이다.
  
코드를 살펴보면 models 모듈의 `Model` 클래스를 상속받은 걸 볼 수 있다. 이 Model 클래스는 model 에 관련된 코드가 이미 작성되어있는 프레임 클래스이다. 이는 장고에서 제공하는 클래스로 개발자에게 **구조를 어떻게 설계할 것인지에 대한 코드만 작성하도록** 하기 위한 것이다. 이외의 것들을 대신 처리해준다.
  
## Model Field

위 코드를 보면 필드에 XxxField() 가 있는데 이는 컬럼의 타입을 지정하는 것과 같다. 데이터의 유형과 제약 조건을 정의한다. 이 필드를 바탕으로 DB 컬럼을 자동생성하고 데이터 입력 시 유효성 검사 등의 필요한 기능을 제공한다. 정확한 필드 정의는 애플리케이션 안정성을 높이는 데 필수적이다.  
`CharField(max_length=10)` 을 보면 CharField 가 필드 유형을 나타내고 max_length=10 은 필드 옵션을 나타낸다. 유형은 타입이고 옵션은 '동작'과 '제약조건'을 정의한다.
