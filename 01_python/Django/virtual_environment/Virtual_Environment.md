# 가상환경, Virtual_Environment
하나의 컴퓨터 안에서 또 다른 독립된 파이썬 환경. Docker 를 생각해보자  
Docker 를 먼저 배우긴 했지만 사실 가상 환경이 Docker 보다 앞의 개념이다. Docker 보다 가벼운 가상 작업 공간이라고 생각하자!
  
우선 이 둘은 **격리의 범위**가 다르다. **가상 환경**은 보통 언어나 패키지 수준의 격리이다. 같은 검퓨터 안에서 서로 다른 라이브러리 버전 충돌을 막는 용도이다. 즉 내 컴퓨터의 운영체제는 그대로 사용하고 그 위에서 Python 만 따로 분리한다.  

반면 **도커**는 실행 환경 전체를 컨테이너로 묶는다. 런타임, 라이브러리, 시스템 도구, 설정 파일 등의 것들을 함께 묶어서 실행한다. 이렇게하면 "내 컴퓨터에서는 되는데 남의 컴퓨터에서는 안된다." 등의 문제를 훨씬 강하게 줄여준다.  

당연하게도 가상환경은 venv 안의 requirement.txt 만을 공유해서 만들어지기 때문에 그 안에 있는 라이브러리 이외의 환경은 컴퓨터마다 달라지고, 이는 위의 문제를 완벽히 막기는 힘들다.
  
정리해서 비교하자면 가상환경은 같은 집에서 내 방만 정리해서 쓰는 것이고 ( 로컬 ) 도커는 생활에 필요한 물건이 다 들어 있는 원룸을 가져오는 것이다. ( 리모트 ) 가상환경은 개인이 사용하기 더 편리하고 도커는 팀 단위로 사용하기가 편하다는 것이다.
  
여기서 마치려고 했지만 찾다보니 `Virtual Machine` 이라는 것도 찾았다! 너무 딥한 내용도 아닌 것 같아서 같이 정리하려고 한다.
  
VM은 운영체제 자체를 통째로 가상화하는 개념이다. 간단히 하자면 가상환경이 방이고 도커가 원룸이라면 VM 은 집인 느낌이다! 가장 크고 무겁지만 가장 강한 격리도를 제공한다. 운영체제를 가상화한다는 것은 한 컴퓨터 안에서 운영체제를 하나 더 돌리는 것과 같다! Window 컴퓨터 위에서 Mac 과 Rinux 를 같이 구동하는 것이다.
