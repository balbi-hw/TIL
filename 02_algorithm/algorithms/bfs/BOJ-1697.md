# 문제 정리

- **문제명 / 번호**: BOJ - 21736 숨바꼭질
- **유형**: BFS
- **핵심 키워드**: 범위 제한
- **상태 정의**: 위치와 걸린 시간
- **핵심 아이디어**: 맥스 범위를 제한해서 최적화 해야함
- **실수 포인트**: 범위 제한을 생각하지 못해서 메모리가 터졌음
- **다음에 바로 떠올릴 한 문장**: 이전에 풀었던 포탈과 비슷한 유형으로 상태 공간이 무한정 커질 수 있어 로컬에선 돌아가지만 사이트에서 메모리가 터질 확률이 높다.

## 코드
1. 최초 제출 코드
```python
from collections import deque

def bfs(n, k, t):
    global min_time

    q = deque([(n, t)])

    while q:
        n, t = q.popleft()

        if n == k:
            min_time = min(min_time, t)    
            return
        
        if n < k:
            q.append((n + 1, t + 1))
            q.append((n - 1, t + 1))
            q.append((n * 2, t + 1))
        
        elif n > k:
            q.append((n - 1, t + 1))

N, K = map(int, input().split())
min_time = float('inf')
bfs(N, K, 0)
print(min_time)
```
문제 조건을 충실히 따르긴 했기에 로컬에서 정답은 나오지만 상태공간이 너무 커져 저지 환경에서는 메모리가 터져버림.  
최적화 후 코드처럼 문제를 확인해 `MAX` 값을 지정하고 방문처리까지 해야 터지지 않고 통과했음.


2. 최적화 후
```python
from collections import deque

def bfs(n, k):
    MAX = 100000

    q = deque([(n, 0)])
    visited = [False] * (MAX + 1)
    visited[n] = True

    while q:
        n, t = q.popleft()

        if n == k:
            return t
        
        for nn in (n -1, n+ 1, n * 2):
            if 0 <= nn <= MAX and not visited[nn]:
                visited[nn] = True
                q.append((nn, t + 1))


N, K = map(int, input().split())
print(bfs(N, K))
```
