## 언제 사용하나?
기본적인 BFS 와는 달리 특수한 환경에서 사용하는 BFS 이다.  
다익스트라와 같이 가중치가 존재하는 환경인데 이 가중치가 0과 1로만 주어졌을 때 사용한다.  
  
다익스트라는 시간복잡도가 `O(ElogE)` 이지만 이 0-1 BFS 는 `O(V+E)` 로 문제를 해결할 수 있다.

## 원리
기본적으로 `deque` 를 활용하는데 `.append()` 메서드 대신 `.appendleft()` 메서드를 사용한다.  
  
1. 덱에서 노드를 꺼낸다.
2. 인접 노드로 이동한다.
3. 이동 전과 후의 코스트가 같으면 이동 후의 상태를 덱의 앞에 집어넣는다.
4. 코스트가 늘었다면 뒤에 집어넣는다.
  
이렇게 하면 코스트가 가장 낮은 상태부터 계산을 계속 진행할 수 있다. 최소힙처럼 작동하는데 연산이 더 간단해서 시간복잡도가 낮다.
  
최소힙은 매 번 값을 비교하는 과정이 있지만 0-1 은 0이면 앞에 넣고 1이면 뒤에 넣는게 다 이기 때문이다.
