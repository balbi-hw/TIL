### [주제]  
**Lazy propagation**  

### [한 줄 요약]  
이 내용은 결국 필요한 만큼만 계산을 한다는 이야기이다.

### [문제 상황]  
내가 막혔던 지점:
- 구간 업데이트를 리프까지 전부 내려가서 직접 반영하는게 시간초과를 유발했다.
- lazy propagation 의 개념은 떠올렸으나 구현에 실패했다.

### [핵심 원리]
1. lazy propagation:
  - "구간 `[start, end]` 의 모든 값에 `diff`를 더한다." 는 사실을 기록해두는 방식
  - 리프까지 내려가서 갱신하지 않고 현재 노드가 담당하는 구간 합만 먼저 반영한 뒤 추후 자식 정보가 필요할 때 `diff`를 내려보낸다.
2. [start, end] 가 업데이트 구간 [L, R] 안에 완전히 들어가면
```python
tree[node] += (end - start + 1) * diff
lazy[node] += diff
```
이렇게만 한다.
  
이후 자식을 볼 필요가 있다면
```python
lazy[left_child] += lazy[node]
lazy[right_child] += lazy[node]
```
이후 반영이 끝나면 마지막에 `laze[node] = 0` 으로 초기화한다.  
이 과정을 흔히 `propagate()` 또는 `push()`라고 한다.

### [예시]
- 입력/상황: 트리에서 `[1, 8]` 구간을 담당하는 노드가 있고, 업데이트도 `[1, 8] + 5` 라면
- 어떻게 동작하는지: 노드의 합에 `8 * 5 = 40` 을 더한다. 그 후 해당 노드의 자식들에 각각 +5 를 해야한다는 표시를 남긴다.

### [해당 문제 정석 코드]
```python
import sys
input = sys.stdin.readline

def build(node, start, end):
    if start == end:
        tree[node] = arr[start]
        return
    mid = (start + end) // 2
    build(node * 2, start, mid)
    build(node * 2 + 1, mid + 1, end)
    tree[node] = tree[node * 2] + tree[node * 2 + 1]


def propagate(node, start, end):
    if lazy[node] != 0:
        tree[node] += (end - start + 1) * lazy[node]

        if start != end:
            lazy[node * 2] += lazy[node]
            lazy[node * 2 + 1] += lazy[node]

        lazy[node] = 0


def update_range(node, start, end, left, right, diff):
    propagate(node, start, end)

    if right < start or end < left:
        return

    if left <= start and end <= right:
        tree[node] += (end - start + 1) * diff
        if start != end:
            lazy[node * 2] += diff
            lazy[node * 2 + 1] += diff
        return

    mid = (start + end) // 2
    update_range(node * 2, start, mid, left, right, diff)
    update_range(node * 2 + 1, mid + 1, end, left, right, diff)
    tree[node] = tree[node * 2] + tree[node * 2 + 1]


def query(node, start, end, left, right):
    propagate(node, start, end)

    if right < start or end < left:
        return 0

    if left <= start and end <= right:
        return tree[node]

    mid = (start + end) // 2
    return (
        query(node * 2, start, mid, left, right)
        + query(node * 2 + 1, mid + 1, end, left, right)
    )


N, M, K = map(int, input().split())
arr = [int(input()) for _ in range(N)]

tree = [0] * (4 * N)
lazy = [0] * (4 * N)

build(1, 0, N - 1)

for _ in range(M + K):
    cmd = list(map(int, input().split()))
    if cmd[0] == 1:
        _, b, c, d = cmd
        update_range(1, 0, N - 1, b - 1, c - 1, d)
    else:
        _, b, c = cmd
        print(query(1, 0, N - 1, b - 1, c - 1))
```
